# Security Policy

## Supported Versions

We actively support and release security patches for the latest release branch of Hostify:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Hostify team takes security seriously. If you discover a vulnerability or potential security risk in Hostify, please do **NOT** open a public GitHub issue.

Instead, please report it privately:

1. **Email:** Contact [123stbn.dev@gmail.com](mailto:123stbn.dev@gmail.com) with the subject `[SECURITY VULNERABILITY] Hostify`.
2. **Details:** Include a detailed description of the vulnerability, affected components, reproduction steps, and any proof-of-concept scripts or logs.
3. **Response:** You will receive an initial response within 48 hours acknowledging receipt of your report.
4. **Resolution:** We will work with you to test and deploy a fix before any public disclosure.
